# Source Governance Checklist v2.1

- [ ] 每份資料已標記 material role。
- [ ] 教師教材與個人筆記沒有被等權混用。
- [ ] 已先抽取來源中的題目/作業/思考題。
- [ ] critical/high Knowledge Unit 具有結構化 source locator。
- [ ] 每個 critical/high KU 與每道題都經逐項檢查，不以「至少存在一個 locator」代替完整性。
- [ ] locator 至少包含 `file + locator_type + locator + evidence + confidence`。
- [ ] 題目答案同樣可回到來源定位。
- [ ] 公式、圖、表、掃描內容若不確定已標記 `VISUAL_CHECK_REQUIRED`。
- [ ] `SOURCE_CONFLICT` 未被模型自行裁決。
- [ ] `SOURCE_NOT_FOUND` 未被模型常識覆蓋。
- [ ] `EXTERNAL_RESEARCH` 與本地教材分區。
- [ ] `synthetic` locator 只允許測試 fixture，不得進正式教材 release。
