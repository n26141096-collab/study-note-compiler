# Layout Reference

## 目的
此文件只保存抽象版面規格，不保存任何使用者教材內容。

## Golden visual characteristics
1. 主題筆記採 A4 高資訊密度左右雙欄。
2. 真正雙欄必須是 Word section columns：內容由左欄自然流到右欄。
3. 頁首可橫跨整頁；正文可從標題開始直接進雙欄。
4. 小節標題用灰階帶狀或粗體快速定位。
5. 核心句、流程與「最後速背」可用淺灰底，但不可大量裝飾。
6. 長表格、Coverage Matrix、跨欄流程可切回全寬單欄。
7. 總索引可採全寬索引 + 下方左右 panel 的混合式版面。
8. 版面優先目標：找得到、看得快、印得清楚；不是雜誌式留白。

## 禁止
- 只有 2-cell table 假裝所有內容都是雙欄。
- 標題在欄尾、正文跑到下一欄而形成孤立標題。
- 表格超出單欄寬度。
- 依賴彩色才能區分資訊層級。
- 每次輸出隨機換樣式。
