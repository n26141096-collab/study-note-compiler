# Learning Science Rules

1. Source correctness first; learning techniques cannot repair wrong notes.
2. Active Recall questions should target a defined Knowledge Unit.
3. Feynman prompts should reveal missing causal links, not reward memorized wording.
4. Spaced repetition defaults to 1/3/7/16/35 days; users may override.
5. Interleaving is optional and useful only when related topics can be meaningfully discriminated.
6. Flashcards are selective: use for atomic facts, formulas, contrasts, trigger conditions; avoid turning long essays into cards.
7. Error log should record misconception class and next corrective action.
